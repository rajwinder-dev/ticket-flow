# hrms api design

## Admin / hr panel

- a hr able to create employees , assign  roles and setup weekly or monthly goals, approve and reject leaves , salary management, view review of each employee , export report in pdf , for eg timeline , every employs should update the task they accomplish with start to end date ,
- when hr set goal , he can also view sub task divided by manages. add chat option manager and admin and employee any query.

## Manager panel

- Manager assign task to employees and able to group teams
- manager set dead lines
- manager give reviews to employees
- track team performance
- notification when dead line is close

## Employee

- view assigned task
- progress update
- request leave
- view feedback history

## Extra featus

- real time notification
- File uploads like resume , docs
- Chat/ feedback thread between manger and employee
- Admin analytics : top performer , avg team performance
- Attendance system (daily check-in/check-out)
